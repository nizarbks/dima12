# Dima12

متجر عربي خفيف، جاهز للنشر على Netlify. الطلبات تفتح واتساب رقم **0656903345** بصيغة دولية، مع الدفع عند الاستلام.

## النشر على GitHub وNetlify

1. أنشئ repository جديد في GitHub، وارفع محتويات هذا المجلد إليه.
2. من Netlify اختر **Add new project → Import an existing project → GitHub**.
3. اختر الـrepository. لا تحتاج Build command؛ Publish directory هو `.`.
4. اضغط Deploy. ستحصل على رابط مثل `dima12.netlify.app`، ويمكن تغييره من **Site configuration → Domain management**.

## استعمال لوحة الإدارة

من أسفل المتجر، اضغط **لوحة الإدارة**. يمكنك إضافة وتعديل وحذف المنتجات. الطلب الذي يتم تأكيده من الموقع يُحفظ في نفس المتصفح، ويفتح كذلك رسالة واتساب مفصلة للتأكيد.

> مهم: النسخة الحالية واجهة متجر كاملة بلا سيرفر، لذلك بيانات لوحة الإدارة محفوظة داخل المتصفح فقط. لكي تظهر طلبات كل الزبناء بشكل مركزي وآمن على أي جهاز، يلزم ربط قاعدة بيانات (مثلاً Supabase) وحساب إدارة محمي. لا تضع رابط لوحة الإدارة كحماية؛ هذا ليس نظام دخول.

## تخصيص سريع

- الصور: استعمل رابط الصورة عند إضافة المنتج من لوحة الإدارة.
- رقم واتساب: موجود في `app.js` في المتغير `WHATSAPP`.
- الألوان: متغيرات الألوان في بداية `styles.css`.
